# The talk

A short talk explaining the shared-brain idea to a mixed technical and non-technical
audience. Delivered internally on 2026-08-19; shared here because the format spreads
faster when someone can borrow the explanation rather than invent it.

| file | what |
| --- | --- |
| [`second-brain-deck.html`](second-brain-deck.html) | 11 slides. Open it in any browser - no server, no build step |
| [`talking-points.md`](talking-points.md) | the argument, per slide |

## Presenting it

Left / right arrow to move. `f` for fullscreen. `Cmd+P` prints one slide per landscape
page if you want a PDF. The URL carries the slide number, so `#7` deep-links.

The slides deliberately carry **one visual and one heading each** - the words live in
`talking-points.md`. That is a choice worth keeping if you rewrite it: the audience reads
a slide or listens to you, never both, and a slide full of bullets loses that race.

Slide 5's directory tree is interactive - click `brain`, then `performance`, then `goals`
during the talk rather than showing it pre-expanded.

## Borrowing it

Take it and change it. The two places worth making your own:

- **Slide 7** lists the presenter's own top-level directories. Swap in yours - the point of
  the slide is that the list is personal, so presenting someone else's undercuts it.
- **Slide 10** contrasts two real arrangements, categorical and timeline. If you know
  people who organise each way, use them; the contrast lands harder with names attached.

Slide 11 closes on the one-line prompt from [`START-HERE.md`](../START-HERE.md), which is
the whole onboarding path.

Fonts load from Google Fonts, so the deck wants a connection to render in Montserrat. It
falls back to whatever geometric sans is installed and still looks fine offline.
